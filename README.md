# StyleBoost - Documentação

O StyleBoost é uma poderosa estrutura de CSS que facilita o desenvolvimento de interfaces web de forma rápida e eficiente. Com uma ampla gama de classes CSS pré-definidas, o StyleBoost permite que os desenvolvedores criem layouts elegantes e responsivos com apenas alguns cliques.

## Recursos

O StyleBoost oferece os seguintes recursos:

### Estilos de Menu
O StyleBoost inclui a classe "mnu001-items" para estilizar os itens de um menu de navegação com uma aparência elegante. Os links do menu são estilizados com a classe "mnu001-items a" e possuem interação suave quando o usuário passa o mouse sobre eles.

### Estilos de Botões
O StyleBoost disponibiliza diferentes estilos de botões, como a classe "btns001" para um botão laranja e a classe "btns002" para um botão azul. Esses botões possuem transições suaves quando o usuário interage com eles. 

### Estilos de Layout
O StyleBoost fornece classes para diferentes tipos de layout, como "style-display-block" e "style-display-flex", permitindo que os desenvolvedores criem facilmente estruturas flexíveis e responsivas. 

### Estilos de Texto
O StyleBoost oferece classes para estilizar o texto, como "styleb-text-decora-none" para remover a decoração de texto. Também há classes para controlar o tamanho da fonte, como "styleb-text-lg" e "styleb-text-xl". 

### Estilos de Cor
O StyleBoost inclui classes para definir cores de texto e de fundo, como "styleb-color-blue" e "styleb-bg-gradient" para aplicar gradientes. 

### Estilos de Borda e Sombra
O StyleBoost permite aplicar facilmente bordas arredondadas com a classe "styleb-border-normal-rounded-lg" e adicionar sombras com a classe "styleb-sombra". 

### Estilos de Espaçamento
O StyleBoost fornece diversas classes para controlar o espaçamento, como "styleb-m-2" para margem e "styleb-pb-3" para preenchimento inferior. 

## Uso

Para utilizar o StyleBoost, basta aplicar as classes CSS apropriadas aos elementos HTML. Por exemplo, para criar um menu com o estilo "mnu001-items", você pode usar o seguinte código:

```html
<nav>
  <ul class="mnu001-items">
    <li><a href="#">Home</a></li>
    <li><a href="#">Sobre</a></li>
    <li><a href="#">Serviços</a></li>
    <li><a href="#">Contato</a></li>
  </ul>
</nav>
```
